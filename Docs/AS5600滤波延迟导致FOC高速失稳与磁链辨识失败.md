# AS5600滤波延迟导致FOC高速失稳与磁链辨识失败：一次从电流环到编码器的排查记录

## 1. 问题背景

项目使用AS5600磁编码器为PMSM FOC提供转子角度，控制周期为10 kHz，电机极对数为7，母线电压约13 V。磁链辨识采用空载dq电压模式：令 `id_ref=0`，缓慢增加 `vq`，在多个稳态转速点采集 `vq`、`iq` 和电角速度，再通过最小二乘法拟合永磁体磁链。

最初的异常现象很有规律：

- 16 RPS以下基本稳定；
- 超过16～20 RPS后速度、`iq` 和 `id` 突然增大；
- 高速时 `id` 可偏离0 A约0.8 A；
- `vq`只增加一点，速度却从约16 RPS跳到30 RPS附近；
- 磁链辨识只能取得少量无效点，最终失败。

理想情况下，开环 `vq` 应缓慢上升，`iq` 和转速随之平滑增加，到达目标速度后保持并采样。实际波形明显不符合这一过程。

## 2. 最初怀疑：电流环、PLL还是辨识判定

排查初期主要考虑了三个方向：

1. d/q电流环PI参数不合适，导致高速解耦能力不足；
2. 角度PLL带宽或滤波参数不合理；
3. 磁链辨识的速度滤波、稳态判定或电压斜坡存在问题。

为了验证电流环影响，曾将电流环带宽从500 Hz提高到1000 Hz。结果d轴电流反而更难控制，说明1000 Hz对于10 kHz采样系统和当前噪声、延迟条件过于激进。随后将电流环带宽降到400 Hz：

```text
d轴 Kp = 4.4496
q轴 Kp = 5.1912
d/q轴离散 Ki = 0.721824 / 控制周期
```

降低带宽改善了电流环稳定裕度，但“固定在16～20 RPS附近失稳”的速度相关特征依然提示：根因很可能不在电流PI本身。

## 3. 关键线索：读取AS5600配置寄存器

根据AS5600手册完善驱动后，在FOC中断启动前读取一次CONF和STATUS寄存器。首次上电输出为：

```text
AS5600 CONF=0x0000 PM=0 HYST=0 OUTS=0 PWMF=0 SF=0 FTH=0 WD=0
AS5600 STATUS=0x67 MD=1 ML=0 MH=0
```

磁铁状态正常：

- `MD=1`：检测到磁铁；
- `ML=0`：磁场不弱；
- `MH=0`：磁场不强。

真正关键的是 `SF=0、FTH=0`。这表示AS5600使用上电默认的16x慢速滤波，并且只走慢速滤波路径。手册给出的16x滤波延迟约为2.2 ms。

## 4. 为什么2.2 ms会在16～20 RPS突然出问题

FOC关心的是电角度，而不是机械角度。电角频率为：

```text
f_e = pole_pairs × speed_rps
```

编码器滤波延迟造成的电角度滞后为：

```text
phase_delay = 360° × f_e × delay
```

对于7极对电机和2.2 ms延迟：

| 机械转速 | 电频率 | 电角度滞后 |
| ---: | ---: | ---: |
| 15 RPS | 105 Hz | 83.2° |
| 16 RPS | 112 Hz | 88.7° |
| 20 RPS | 140 Hz | 110.9° |
| 30 RPS | 210 Hz | 166.3° |

这与实测阈值高度吻合。16 RPS附近反馈角已经滞后约90°，原本施加到q轴的电压和电流开始大量投影到d轴。随着转速继续上升，角度滞后进一步增加，坐标变换失准，可能形成正反馈，于是出现 `id`增大、转矩突变和急剧加速。

PLL可以滤除量化噪声并估计速度，但普通PLL跟踪的是已经延迟的测量角度，并不会自动消除传感器内部2.2 ms的固定延迟。因此单纯修改PLL或电流环不能根治问题。

## 5. 修复方法：使用固定、低延迟的2x滤波

最终在AS5600上电初始化中写入易失CONF配置：

```c
AS5600_SetFilterConfig(
    AS5600_SLOW_FILTER_2X,
    AS5600_FAST_FILTER_SLOW_ONLY,
    true
);
```

配置含义：

- `SF=3`：2x慢速滤波，延迟约0.286 ms；
- `FTH=0`：不使用阈值触发的快速滤波，保持延迟连续、确定；
- `verify=true`：写入后等待至少1 ms并回读校验；
- 只修改易失寄存器，不执行BURN，不写OTP，每次上电重新配置。

修改后上电输出为：

```text
AS5600 filter configured: SF=3 (2x), FTH=0 (slow-only)
AS5600 CONF=0x0300 PM=0 HYST=0 OUTS=0 PWMF=0 SF=3 FTH=0 WD=0
AS5600 STATUS=0x67 MD=1 ML=0 MH=0
```

此时20 RPS的理论电角度滞后降为：

```text
360° × 140 Hz × 0.286 ms ≈ 14.4°
```

30 RPS时也只有约21.6°，FOC重新获得足够的角度裕量。

## 6. 驱动层同时修复的问题

AS5600具有内部寄存器地址指针。高速角度路径先将指针定位到RAW ANGLE高字节，随后直接连续读取两个字节。读取CONF或STATUS会改变这个指针，因此驱动必须在普通寄存器访问结束后恢复RAW ANGLE指针，否则下一次中断可能把其他寄存器数据当成角度。

驱动最终采用以下原则：

- 配置/状态寄存器只在10 kHz FOC中断启动前访问；
- 所有普通寄存器读写结束后恢复RAW ANGLE指针；
- CONF写入使用“读—修改—写”，保留手册注明的出厂保留位；
- 配置写入后等待至少1 ms并回读校验；
- 普通写接口禁止误写BURN寄存器；
- I²C读取失败时不覆盖最后一次有效角度；
- BURN Setting命令使用手册规定的 `0x40`，BURN Angle为 `0x80`。

初始化也被拆成两层：

- `bsp_as5600HwInit()`：仅上电调用一次，初始化I²C、配置滤波、读取诊断信息并定位RAW ANGLE；
- `bsp_as5600ResetTracking()`：电机状态切换时只清软件跟踪量，不访问I²C。

这样避免了原先每次启动电机都重新初始化I²C，并与持续运行的角度中断竞争。

## 7. 修复后的磁链辨识结果

磁链辨识速度点恢复为额定转速的 `{3/8, 4/8, 5/8, 6/8}`。额定转速2400 RPM，即40 RPS，对应15、20、25、30 RPS。

实测有效点为：

| 点 | 平均转速/RPS | vq/V | iq/A | id/A | 单点磁链/Wb |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 14.3 | 2.170 | 0.037 | 0.000 | 0.00328 |
| 1 | 19.1 | 2.826 | 0.042 | 0.000 | 0.00322 |
| 2 | 23.8 | 3.440 | 0.046 | 0.000 | 0.00316 |
| 3 | 28.5 | 4.026 | 0.051 | -0.000 | 0.00309 |

拟合模型为：

```text
vq - R·iq = ψf·ωe + Vdt
```

固件使用未舍入采样数据得到：

```text
ψf  = 0.002896 Wb
Vdt = 0.2586 V
Ke  = 0.020270 V·s/rad_mech
Kt  = 0.030405 N·m/A
```

用日志中的舍入数据重新计算，得到 `ψf≈0.002894 Wb`、`R²≈0.9993`，说明四个点具有很好的线性一致性。单点磁链随速度略微下降，是因为单点计算没有分离约0.26 V的固定截距；最小二乘斜率才是最终磁链估计。

采样窗口内速度仍有较明显纹波，后续可以优化PLL速度输出或稳态判定，但 `id≈0`、四点全部有效且反电势拟合线性良好，因此当前磁链结果可以作为固件默认参数。生产或最终标定时建议重复辨识3次，比较磁链结果的重复性。

## 8. AS5600配置是否还有优化空间

当前配置适合FOC角度反馈：

- `PM=NOM`：保持正常模式，避免低功耗唤醒延迟；
- `HYST=OFF`：避免额外角度死区；
- `SF=2x`：最低固定滤波延迟；
- `FTH=slow-only`：避免运行中跨阈值时滤波延迟发生跳变；
- `WD=OFF`：避免长时间未访问后进入低功耗模式；
- `OUTS/PWMF`：只影响模拟/PWM输出，I²C角度读取时保持默认即可。

若低速角度噪声将来成为主要问题，可以试验 `SF=4x`配合快速滤波阈值，但阈值切换可能产生延迟变化。对于依赖精确相位的FOC，当前 `2x + slow-only`通常比“低速更平滑、高速自动切换”的配置更容易建模和补偿。

## 9. 排查经验总结

这次问题最重要的经验是：编码器“能正确读出角度”并不代表它适合高速FOC。需要同时关注分辨率、总线速度、内部数字滤波延迟，以及机械角误差乘以极对数后的电角度误差。

遇到“低速正常、达到固定转速后突然失稳”时，可以按以下顺序排查：

1. 计算传感器、通信和算法总延迟对应的电角度相移；
2. 同时观察原始角度、PLL角度、`id/iq`和电压限幅；
3. 检查传感器上电默认配置，而不是只检查代码中的采样频率；
4. 一次只改变一个变量，并保留配置回读日志；
5. 用多个速度点的线性拟合验证最终参数，而不是只相信单点结果。

最终，问题并不是磁链辨识公式本身失效，而是AS5600默认滤波产生的电角度滞后破坏了dq坐标系。把传感器延迟纳入控制系统分析后，现象、阈值和修复结果能够完整对应起来。

# AS5047 单帧读取实现（2026-09-28）

默认 `AS5047_READ_MODE=AS5047_READ_MODE_BLOCKING`。运行期每次 FOC 只发送一个 16-bit 命令；正常命令为 ANGLECOM，接收上一次命令对应的角度。第一帧、诊断访问后的第一帧不发布角度。SPI 仍为 mode 1、16 bit、7.5 MHz。

## 数据时间与接口

- `Encoder_AS5047.raw_angle/mech_angle/angle` 保留真实测量（angle 含零位）；预测不覆盖这些字段，不增加 `valid_sample_seq`。
- 采样时间采用前一条命令的 CS 上升沿 DWT 时间，按 AS5047 SPI 响应流水线归属记录。该时间是 SPI 寄存器取数时刻，不代表传感器内部磁场测量的精确时刻。
- 服务层使用 `bsp_as5047GetControlAngle()`，按最近真实样本速度及实际年龄外推到当前读取时刻。正常阻塞模式约补一拍，DMA 模式可接近两拍；不再硬编码“一拍 DMA 延迟”。
- 速度仅由两个真实样本的角度差与时间差更新，预测不反馈到速度估计。保留 LPF=0.1；它的加速滞后和模型 PLL 配合仍需上板验证。此实现补偿通信年龄，不额外补偿 PWM 生效延迟或重复补偿传感器 DAEC。
- 上电零位校准没有周期调用，使用 `bsp_as5047GetAngleImmediate()` 两帧即时读取，调用时 FOC 必须静止。服务层的任务上下文 Update 为该启动场景保留此路径；不要在运行中的任务里另行调用 Encoder_Update。
- 原始寄存器 API 保持多帧事务，整个事务占有总线；高优先级调用遇占用立即返回，不等待被抢占的任务。DMA 正在流式运行时普通寄存器访问返回 BUSY。

## 超时与错误

| 参数 | 当前默认值 | 含义 |
|---|---:|---|
| AS5047_FRAME_TIMEOUT_US | 12 us | 寄存器轮询的单帧截止时间；退出清理/中断抢占仍应实测 |
| AS5047_DMA_TIMEOUT_US | 150 us | 包含低优先级完成 IRQ 调度延迟的异步传输截止时间 |
| AS5047_MAX_SAMPLE_AGE_US | 1000 us | 最后真实样本的最大年龄 |
| AS5047_PREDICT_MAX_FRAMES | 10 帧 | 预测帧数上限，和年龄限制取先到者 |
| ENCODER_FAULT_STREAK_N | 10 帧 | 连续非真实新样本触发服务层故障，10 kHz 下约 1 ms |

奇偶校验错误和 EF 不发布新角度；在后续单帧槽发送 ERRFL，再重新建立 ANGLE 流水线。ERRFL 响应有专门类型，不能被解释为角度。传输超时后清接收残留/OVR 并重新预热，不在 FOC 内追加两个阻塞 NOP。故障计数不被 REPEAT 或预测清零。

DWT 在初始化时启用并检查；轮询同时具有次数上限，CS 延时也有次数上限。DWT 失效时不允许初始化为可用编码器。断开 MISO 不一定使 SPI 主机超时，主机仍会自行产生时钟；测试断线需同时检查错误响应与磁场诊断，不能只观察超时计数。

DMA 采用专用寄存器传输，初始化仍使用 HAL 配置；不再经过 HAL SPI DMA 完成函数的 HAL_GetTick 等待。只有消费端启动传输，RX 完成/两通道错误 IRQ 仅发布完整帧。发布和取消使用短临界区及传输代次，防止被 FOC 取消的旧 IRQ 发布过期结果。TX 完成中断关闭。连续传输/缺帧错误达到上限后停止流，停机上下文可显式重新启动；不自动恢复功率输出。

## 观测与验证

RTT `get` 增加 `enc-stream`：模式、真实样本序号、年龄、预热次数、超时、过期次数、消费函数最近/最大周期数。`read_cycles` 包含函数内工作和抢占，不包含随后服务层角度换算，也不等于完整 FOC WCET。

已完成：

- 默认阻塞 Debug 固件编译链接。
- 独立 `build/AS5047_DMA`，用 `-DAS5047_READ_MODE=1` 编译链接，不改变默认固件。
- `tests/as5047_pipeline_test.c`：首次响应丢弃、前一命令时间戳归属、奇偶错误、EF/ERRFL 恢复、重新预热、DWT 回绕及全部 16384 个角度码。使用主机 GCC 的 `-std=c11 -Wall -Wextra -Werror` 编译运行。

尚未上板验证。先在功率关闭时确认：稳态每次 FOC 一个 CS 脉冲、16 个 SCK、真实序号持续增加、年龄符合模式；再验证校准、低速正反转、速度阶跃、错误响应、DMA IRQ 延迟/丢失和超时。测量完整 FOC WCET，并确认临界区和 CS 建立/保持满足实际芯片时序。DMA 寄存器路径及补偿后的控制性能不能仅以编译通过判定验收。
